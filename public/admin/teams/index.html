Teams

Link each Trackman team code to its school. A game belongs to the home team's conference for that season, which lets coordinators look at only their conference's games. Fall games count toward the next spring, so Fall 2026 scrimmages use 2027 conferences. Use an override only for a team the directory doesn't cover, like a D3 or NAIA school.
